# 📚 Aula 01 — Apresentação da Disciplina e Contextualização

## 📖 Sobre a aula

A primeira aula apresenta a disciplina de **Frameworks Front-end**, seus objetivos, conteúdos, metodologia de ensino e critérios de avaliação.

Também são introduzidos conceitos fundamentais do desenvolvimento Front-end e a importância dos frameworks no desenvolvimento de aplicações Web modernas.

## 🌐 Desenvolvimento Front-end

O Front-end é a camada da aplicação com a qual o usuário interage diretamente.

Ele é responsável por:

- Criação das interfaces;
- Organização visual dos elementos;
- Experiência do usuário (UX);
- Comunicação com sistemas responsáveis pelo processamento dos dados.

## 🧩 Frameworks Front-end

Frameworks facilitam a criação e organização de aplicações Web modernas.

Foram apresentados conceitos relacionados a:

- React;
- Vue;
- Angular;
- Componentização;
- Arquitetura de aplicações;
- Estado;
- Rotas;
- Gerenciamento de dados;
- Integração com APIs.

## 🟨 Vanilla JavaScript

A aula também apresenta o **Vanilla JavaScript**, que corresponde ao uso do JavaScript puro, sem frameworks ou bibliotecas externas.

Ele pode ser utilizado para:

- Manipular páginas Web;
- Criar lógica de interfaces;
- Trabalhar com interações do usuário;
- Realizar comunicação com servidores.

## 🎨 UX, UI e Arquitetura

Também são abordados conceitos relacionados à arquitetura de sites, prototipação e UX/UI.

O processo envolve:

- Definição de escopo;
- Prototipação;
- Validação de ideias;
- Refinamento da usabilidade;
- Desenvolvimento e iteração de projetos.

## 🔄 Versionamento e Deploy

A aula apresenta uma introdução ao **Git, GitHub e Deploy**.

O objetivo é compreender como os projetos podem ser versionados e posteriormente publicados na Web.

## 🎯 Objetivos da disciplina

Ao final da disciplina, o aluno deverá ser capaz de:

- Desenvolver interfaces modernas;
- Criar aplicações utilizando frameworks Front-end;
- Utilizar Git e GitHub;
- Publicar aplicações na Web.

## 📝 Atividades

Entre as atividades propostas estão:

1. Criar um projeto utilizando HTML, CSS e JavaScript;
2. Conectar o projeto ao GitHub;
3. Realizar o deploy da aplicação utilizando a Vercel;
4. Criar um resumo da aula em Markdown;
5. Escolher um framework Front-end e elaborar um relatório técnico.

## 💡 Importância

A disciplina busca preparar o aluno para o desenvolvimento de aplicações Web modernas, trabalhando desde os fundamentos do Front-end até a utilização de frameworks, versionamento e publicação de projetos.
