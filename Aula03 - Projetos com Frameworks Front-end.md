# 🚀 Aula 03 — Projetos com Frameworks Front-end

## 📖 Sobre a aula

A terceira aula apresenta a proposta de desenvolvimento de projetos utilizando diferentes **Frameworks Front-end**.

O objetivo é colocar em prática os conceitos estudados e comparar diferentes tecnologias utilizadas no desenvolvimento Web.

## 🧩 Frameworks utilizados

Os projetos deverão utilizar quatro tecnologias:

- React;
- Vue;
- Angular;
- Next.js.

Cada projeto deve apresentar uma página:

- Funcional;
- Responsiva;
- Organizada;
- Desenvolvida utilizando componentes;
- Utilizando recursos básicos da tecnologia escolhida.
